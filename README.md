# Frontend Interview Prep

[GreatFrontEnd](https://www.greatfrontend.com) 문제를 매일 하나씩 풀며 정리하는 저장소입니다.

## Structure

| Folder           | Content                                        | Format              |
| ---------------- | ---------------------------------------------- | ------------------- |
| `javascript/`    | JS 유틸 함수 구현 (debounce, promise.all, ...) | `.ts` + test        |
| `ui/`            | UI 컴포넌트 (accordion, tabs, modal, ...)      | React `.tsx` + test |
| `algo/`          | 알고리즘 코딩테스트                            | `.ts` + test        |
| `quiz/`          | 지식 퀴즈 (이벤트 루프, 클로저, CSS, ...)      | `.md`               |
| `system-design/` | 프론트엔드 시스템 디자인                       | `.md`               |

## Usage

```bash
npm install
npm run new -- javascript debounce   # javascript | ui | algo | quiz | system-design
npm test                             # vitest run
npm run test:watch
npm run typecheck
npm run lint
```
